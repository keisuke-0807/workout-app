# 筋トレ記録（個人用 PWA）

部位ごとに「いつ・どの種目を・どれだけやったか」を記録し、カレンダーで振り返るアプリです。
iPhoneのホーム画面に追加して使います。データはすべて端末内（IndexedDB）に保存され、外部には送信されません。

## 機能
- 今日の記録：種目を選んで重さ×回数などを入力（前回の内容が最初から入る／自動保存）
  - 記録の形式：重さ×回数／回数のみ／秒／時間・距離（有酸素）
  - 前後の日に移動して過去の記録も編集できる。日ごとのメモ
- カレンダー：記録した日に部位の色の点を表示。その月の日数・今週の日数・連続日数。日付をタップでその日のメニュー
- 部位：胸・背中・肩・腕・脚・腹・有酸素
- 種目の管理（追加・名前変更・削除。最初から代表的な種目を登録済み）
- バックアップの書き出し・読み込み（JSON）
- オフライン対応、更新のお知らせ、ダークモード

## ファイル構成
| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み（下のタブ） |
| app.js | 画面表示と操作 |
| db.js | データ保存（IndexedDB）と初期の種目一覧 |
| style.css | デザイン |
| version.js | バージョン番号（sw.js と共用） |
| sw.js | オフライン対応（Service Worker） |
| manifest.webmanifest / icons/ | ホーム画面用の設定とアイコン |

## PCで動かす
```
cd workout-app
python -m http.server 8000
```
http://localhost:8000 を開きます。

## 更新するとき
ファイルを変更したら `version.js` の `APP_VERSION` を1つ上げてから公開します。
アプリを開いたとき（またはバックグラウンドから戻ったとき）に「新しいバージョンがあります［更新］」と表示されます。

## 注意
- Safariのデータを消去したり、ホーム画面のアイコンを削除したりすると記録も消えます。ときどき「設定 → バックアップを書き出す」で書き出してください。
- Safariで開いたときと、ホーム画面から開いたときでは保存場所が別になります。普段はホーム画面から使ってください。
